上传发布

把符合发布规范的文件打成一个压缩包上传， 站点会自动解包并归档到 apps/<应用ID>/<版本号>/。 支持 .zip、.tar、.tar.gz、.tar.bz2。

发布包 







  
版本号怎么确定

  
按以下顺序，前一步成功就不看后面的：

  
    
    
  1. 表单里的版本号，或接口的 ?version= 参数
    2. 
    
  2. 压缩包里唯一的一级目录，且目录名是合法版本号
    3. 
    
  3. 压缩包根目录下 release.json 的 version 字段
    4. 
  

  

    同名版本已存在时会整体替换。压缩包里的 release.json、
    CHANGELOG.md、SHA256SUMS 会按规范被识别，
    平台与架构则从安装包文件名推断。
  






  
命令行上传

  
管理员用 updatesite token <应用ID> 生成令牌后：

  
curl -fS -X POST \
  -H "Authorization: Bearer <令牌>" \
  -F "file=@release.zip" \
  -F "version=1.2.0" \
  {{if .Site.BaseURL}}{{.Site.BaseURL}}{{else}}http://<站点地址>{{end}}/api/v1/apps/<应用ID>/upload

  

    也可以直接发送原始归档：curl --data-binary @release.tar.gz
    -H "Content-Type: application/gzip" -H "Authorization: Bearer <令牌>"
    ".../upload?version=1.2.0"
